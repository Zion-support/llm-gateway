# LLM Gateway

Unified API gateway for multiple LLM providers — smart routing, automatic fallbacks, rate-limit handling and usage analytics. Part of the Zion Tech Group App Network.

**Live app:** https://ziontechgroup.com/llm-gateway/

## About
LLM Gateway is a free, browser-based tool from the [Zion App Network](https://ziontechgroup.com/apps/) (600+ open-source AI & IT ops apps). Category: **Developer & LLM Tools**.

## Features
- Single endpoint across OpenAI, Anthropic, Google, Mistral and open models
- Automatic failover and retry with per-provider health tracking
- Cost-aware routing to the cheapest model meeting quality targets
- Request logging, latency and token-usage analytics
